# Como editar o site

O conteúdo do portfólio pode ser atualizado pela interface do [Pages CMS](https://app.pagescms.org/), sem editar HTML ou código. As alterações salvas atualizam os arquivos do repositório e o GitHub Pages publica a nova versão automaticamente.

## Primeira configuração

1. Entre em https://app.pagescms.org/ com a conta GitHub proprietária do repositório `Raiugami/brunafesta-site`.
2. Instale o aplicativo Pages CMS nessa conta e selecione o repositório `brunafesta-site`.
3. Abra o repositório no Pages CMS. A configuração em `.pages.yml` apresentará as áreas de edição.
4. Convide a Bruna como colaboradora pelo e-mail dela no Pages CMS. Ela poderá entrar pelo convite sem ter uma conta ou permissão no GitHub.

## O que pode ser alterado

- **Textos e fotos do site:** capa, apresentação do arquivo, Perfil, experiência, referências pessoais e Contato.
- **Matérias e trabalhos:** título, veículo, data, formato, tema, link e imagem. O acervo continua organizado automaticamente dos mais recentes para os mais antigos.
- **Fotos:** use os campos de imagem para enviar ou escolher arquivos. Prefira WebP para manter o carregamento leve.

Colaboradores do Pages CMS podem editar conteúdo e imagens, mas não alterar a configuração do CMS nem convidar outras pessoas. Os textos e os dados são guardados em `data/site-content.json` e `data/works.json`; as imagens enviadas ficam em `assets/uploads/`.

## Onde encontrar o material
